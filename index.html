Your AI knows the internet. DayBrain helps it know your workday.

DayBrain is a private, local memory layer for AI assistants. It records useful work context on your machine and makes it available when you need it—without sending your activity to a hosted DayBrain account.

View source on GitHub Quick start

Local by design

Activity and memory stay in a local SQLite database under your control.

Works with AI tools

Connect through MCP so compatible assistants can retrieve relevant context.

Open source

Inspect the implementation, run it yourself, and contribute on GitHub.
